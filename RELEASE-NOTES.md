# Disney Explode

- **Windows x64:** `DisneyExplode.exe` ou pacote ZIP, com .NET incluído. Interface completa; alguns recursos requerem administrador e drivers adicionais.
- **Linux x64:** `DisneyExplode-linux-x64.tar.gz`. Edição reduzida de terminal com CPU, memória, discos, temperaturas disponíveis e relatório JSON. Requer glibc 2.35+; sem interface WPF, DirectX, overclock ou drivers Windows.

No Linux, extraia o pacote e execute `./DisneyExplode-linux-x64`. Use `--output relatorio.json` para exportar.
